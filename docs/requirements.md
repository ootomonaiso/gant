# ガントチャート型タスク管理アプリ 要件定義書

最終更新: 2026-07-20

## 1. 目的・コンセプト

ガントチャートを中心に、タスクの**期間・進捗・依存関係**を視覚的に管理するデスクトップ Todo アプリ。個人が自分の仕事を計画・追跡することを目的とする。

- 形態: Electron 製デスクトップアプリ（Windows 中心、将来 Mac も視野）
- 利用者: 当面は **自分専用・ローカル完結**（アカウント / クラウド同期なし）。ただし
  **将来的に複数人・複数端末で使うことを見据えた設計**にする（後述の同期対応）
- 位置づけ: 「Todo リスト」＋「ガントチャート」を1つにした個人用プランナー

## 2. 想定ユーザー・利用シーン

- 単一ユーザーが1台の PC で使用する
- 複数プロジェクト / 案件を横断してタスクを管理
- 「いつ・何を・どこまで進んだか」を1画面で俯瞰したい

## 3. スコープ

### 3.1 やること（本アプリの対象）
- タスクの CRUD（作成・編集・削除・複製）
- ガントチャートでの期間・進捗の可視化と編集
- タスクの階層（サブタスク）・依存関係の管理
- リスト / カンバン ビューでの表示
- フィルタ・検索
- ローカル DB への永続化

### 3.2 やらないこと（今回の対象外）
- マルチユーザーの**実運用**（権限管理・チーム共有 UI）※データ設計だけ先行して備える（§7.1）
- クラウド同期・サーバー連携の**実装**（差し替え可能な設計にとどめる）
- モバイルアプリ

### 3.3 今回入れる（追加要件）
- **デスクトップ通知**（OS 通知）: 開始時刻 / 期限接近 / 期限超過 / タスク個別リマインダー
- **同期に備えたデータ設計**: UUID 主キー・updated_at・soft delete（§7.1）

## 4. 機能要件

### 4.1 タスク属性
| 項目 | 内容 | 必須 |
|------|------|------|
| タイトル | タスク名 | ○ |
| 開始日時 / 終了日時 | 期間。**時間単位まで**指定可能 | ○ |
| 進捗率 (%) | 0〜100。バーに塗りで表示 | ○ |
| ステータス | 未着手 / 進行中 / 完了 など | ○ |
| 優先度 | 高 / 中 / 低（色分け） | ○ |
| カテゴリ / プロジェクト | 分類・色分けの単位 | ○ |
| タグ | 任意の複数ラベル | △ |
| 親タスク | サブタスク階層（ツリー表示） | ○ |
| 依存関係 | 先行 / 後続タスク（終了→開始が基本） | ○ |
| メモ | 自由記述 | △ |

### 4.2 ガントチャート（自作 / SVG or Canvas）
- タスクを行、時間軸を横軸としたバー表示
- **ズーム単位の切替**: 時間 / 日 / 週 / 月
- **バーのドラッグ操作**:
  - バー本体ドラッグ → 期間ごと移動
  - 端（ハンドル）ドラッグ → 開始 / 終了の伸縮
- 進捗率をバー内の塗りで表示
- **依存関係の矢印**を描画（先行→後続）
- **今日ライン**（現在日時の縦線）を表示
- **期限警告**: 期限が近い / 超過したタスクを強調表示
- サブタスクの折りたたみ / 展開（階層ツリー）
- 優先度・カテゴリによる色分け

### 4.3 その他ビュー
- **リストビュー**: 表形式でソート・一括編集
- **カンバンビュー**: ステータス列でカード移動
- ガント / リスト / カンバンをタブ等で切替、選択状態は共有

### 4.4 フィルタ・検索
- プロジェクト / カテゴリ / ステータス / 優先度 / 期間で絞り込み
- キーワード検索（タイトル・メモ）

### 4.5 データ管理
- 起動時に前回状態を復元
- インポート / エクスポート（JSON、将来検討）

### 4.6 デスクトップ通知
- OS のデスクトップ通知を発火する。発火条件:
  - **開始時刻**に到達（未完了タスク）
  - **期限接近**: 終了時刻の「リードタイム分前」（既定 60 分、設定で変更可）
  - **期限超過**: 終了時刻を過ぎた未完了タスク
  - **個別リマインダー**: タスクごとに設定した時刻
- 通知クリックで該当タスクの編集を開く
- 設定画面で「通知 ON/OFF」「リードタイム（分）」を変更可能
- 重複発火は記録テーブルで抑止。時刻を変更すると再通知される

## 5. 非機能要件
- **性能**: 数百〜数千タスクでもガント描画・スクロールが滑らか
- **永続化**: SQLite（アプリ終了後もデータ保持）
- **オフライン**: 完全ローカル動作、ネット接続不要
- **データ保管場所**: OS のユーザーデータ領域（`app.getPath('userData')`）
- **バックアップ**: DB ファイルのコピーで対応可能な単一ファイル構成

## 6. 技術構成（案）

| レイヤ | 採用技術 |
|--------|----------|
| デスクトップ基盤 | Electron |
| ビルド / 開発 | Vite（electron-vite 想定） |
| UI フレームワーク | **Vue 3**（Composition API + TypeScript 推奨） |
| 状態管理 | Pinia |
| ガント描画 | **自作**（SVG 主体を推奨。多数バー時は Canvas も検討） |
| データ保存 | **SQLite**（`better-sqlite3` を main プロセスで実行） |
| プロセス間通信 | Electron IPC（renderer ⇔ main、`contextBridge` で安全に公開） |

### 構成方針
- DB アクセスは **main プロセス**に集約し、renderer からは IPC 経由で呼ぶ（`contextIsolation: true` / `nodeIntegration: false`）
- ガントは再利用可能な Vue コンポーネントとして自作。時間→X座標の変換を担う「タイムスケール」ロジックを核にする

## 7. データモデル

```
Project(id, name, color, sort_order, created_at, updated_at, deleted_at)
Task(
  id, project_id, parent_id,
  title, note,
  start_at, end_at,        -- 日時（時間単位）
  progress,                -- 0-100
  status,                  -- todo / doing / done
  priority,                -- high / mid / low
  sort_order,
  reminder_at,             -- 個別リマインダー（任意）
  created_at, updated_at, deleted_at
)
Dependency(id, predecessor_id, successor_id, type, created_at, deleted_at)  -- type: FS
NotificationLog(task_id, key, fired_at)   -- 通知の重複発火防止
Tag(id, name)                             -- 将来
TaskTag(task_id, tag_id)                  -- 将来
```

### 7.1 同期（複数人・複数端末）への備え
今はローカル完結だが、後で同期を足せるよう次を先行導入する。

- **UUID 主キー**（`id` は文字列）: 端末をまたいでも ID が衝突しない
- **`updated_at`**: 差分同期の基準時刻（Last-Write-Wins などに利用）
- **`deleted_at`（soft delete）**: 物理削除しないので「削除」も差分として同期できる
- **データアクセスの一元化**: renderer は SQLite を直接触らず IPC / Repository 経由。
  将来この Repository をサーバー API 実装に差し替えれば、UI をほぼ変えずに同期化できる（§アーキテクチャ）

> 次段階（本要件の対象外）: ユーザー/所有者スコープ（`owner_id`）、認証、サーバー同期エンドポイント。

## 8. 画面構成（初期案）
- メインウィンドウ
  - 左: プロジェクト / フィルタのサイドバー
  - 中央: ビュー切替（ガント / リスト / カンバン）
  - 上部: ズーム切替・検索・今日へジャンプ
- タスク編集: ダイアログ or 右パネル

## 9. 開発フェーズ（案）
1. **基盤**: Electron + Vue + Vite + SQLite の疎通、タスク CRUD（リスト表示のみ）
2. **ガント v1**: SVG でバー描画 + 今日ライン + ズーム
3. **編集**: バーのドラッグ移動・伸縮
4. **階層・依存**: サブタスク、依存矢印
5. **ビュー拡張**: カンバン、フィルタ・検索、期限警告
6. **仕上げ**: エクスポート、設定、パッケージング

## 10. 未決事項 / 今後詰める点

- 依存関係の種類（FS のみか、SS/FF/SF も持つか）
- 繰り返しタスクの要否
- OS 通知（期限リマインド）の要否
